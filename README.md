# T3 Code — интерактивная учебная карта

Неофициальная карта для знакомства с устройством [T3 Code](https://github.com/pingdotgg/t3code): кто за что отвечает, как проходит запрос, что хранится в истории и что получает внешний агент.

Учебный замысел, вопросы и направление работы — Катя. Объяснения и интерактивная страница подготовлены с помощью Codex, ИИ-помощника OpenAI, в диалоге с Катей. Материал предназначен для знакомства с проектом, в том числе для людей без опыта программирования.

## Скачать и открыть

**[Скачать карту одним ZIP — v0.1.0](https://github.com/katiasmolskaia-hub/t3-code-learning-map/releases/download/v0.1.0/t3-code-learning-map-v0.1.0.zip)**

1. Скачайте ZIP и распакуйте его целиком в отдельную папку.
2. В папке **t3-code-learning-map** откройте **index.html** в Chrome, Edge или другом современном браузере.
3. Выбирайте острова, переходите между масштабами и раскрывайте объяснения и исходные фрагменты.

Установка и сервер для карты не нужны. Она работает без сети; внешние ссылки на GitHub открываются только по нажатию. T3 и модели карта не запускает. Для полноэкранного просмотра в Chrome или Edge на Windows нажмите F11.

Альтернативно можно скачать репозиторий через **Code → Download ZIP**, распаковать его и открыть **index.html**. Основная страница самодостаточна; инструкция и лицензия также включены в комплект.

## Что внутри

- **Вся система:** приложение, окно чата, сервер, внешний агент, история и файлы.
- **Путь запроса:** команда, решение, сохранение, выполнение и отображение.
- **История и восстановление:** сохранённое намерение и внешняя работа.
- **Что получает агент:** преобразование, бюджет и доставка контекста.
- **Файлы и откат:** снимки и согласование файлов с разговором.

У каждого компонента есть простое объяснение, пример, техническая подробность, границы знания и ссылки на исходники. [Весь учебный текст](guide.ru.md) можно читать отдельно.

## Основание и границы

Разбор закреплён за снимком T3 от **17.10.2026**, commit [4b1024dafe4766ea7c59546936c21ce0fab8acb3](https://github.com/pingdotgg/t3code/tree/4b1024dafe4766ea7c59546936c21ce0fab8acb3). В комплект встроены 23 исходных фрагмента, включая лицензию. Они сверены с зафиксированным кодом. Это выборочный статический разбор, а не полный аудит проекта.

Проверялась работа самой учебной страницы. T3, его агенты, реальные подключения и сценарии аварий в этом исследовании не запускались. Вопросы и гипотезы не обозначают воспроизведённые дефекты. Расположение островов условное; схема не отражает физическое размещение программы.

Четыре опорных понятия — архитектура, отношения, среда и потенциал — используются как язык для человеческих вопросов. Преимущество рамки для анализа самим ИИ здесь не установлено. Внутренние тексты методологии, отдельные отчёты Наблюдателя, пользовательская история, ключи и полная копия T3 в комплект не входят.
